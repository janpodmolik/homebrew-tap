# homebrew-tap

Homebrew formulae for Jan Podmolik's tools.

```bash
brew install janpodmolik/tap/skiprun          # tagged release
brew install --HEAD janpodmolik/tap/skiprun   # current main of the tool
```

| Formula | What it is |
| --- | --- |
| `skiprun` | Build, install and launch a [Skip](https://skip.dev) app on the iOS simulator, the Android emulator or a phone — https://github.com/janpodmolik/skiprun |

The formula file is maintained in the tool's own repository
(`Formula/skiprun.rb`) and copied here on each release.
